# Practice entries

The seven practice entries have moved to the `practice/` folder and are
published on the site under "Practice", each labelled as written in hindsight.

How to learn from them:

1. Read one entry and its matching case study.
2. Close the file and rewrite each section from memory, in your own words.
3. Compare your version with the draft, and note where your reasoning differed.
4. Change the prediction and probability to what you would have chosen.

Each section holds a hidden note starting with `REWRITE:` that poses a question
to think about. The notes do not appear on the website.
